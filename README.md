# NumPy-Mathematical-Operations-Python

NumPy Mathematical Operations, Equations & Sequences

This project contains my hands-on exercises from the NumPy Mathematical Operations, Equations & Sequences lesson.

## Project Overview

The exercises demonstrate how NumPy can be used for numerical calculations, mathematical operations, sequences, and basic data analysis using real-world scenarios.

## Exercises

1. Business Analytics — Sales Performance Calculator

Analyzed a week's daily sales data using NumPy.

The exercise covered:

- Creating and inspecting NumPy arrays
- Calculating total sales
- Calculating average daily sales
- Applying a 10% sales increase
- Calculating the difference between adjusted and original sales
- Interpreting total and average sales

2. Education Analytics — Student Performance

Analyzed student scores to understand variation around the mean.

The exercise covered:

- Calculating the mean score
- Calculating deviations from the mean
- Squaring deviations
- Summing squared deviations
- Understanding the steps involved in calculating standard deviation
- Interpreting variation in student performance

3. Engineering & Scientific Computing — Trigonometric Series and Convergence

Explored a mathematical series using trigonometric functions and different numbers of terms.

The exercise covered:

- Converting degrees to radians
- Using "np.sin()"
- Creating sequences with "np.arange()"
- Element-wise division
- Calculating series sums with "np.sum()"
- Comparing results as the number of terms increases
- Understanding convergence

## Bonus — Energy Consumption Analysis

Built a small numerical experiment using electricity consumption data from a seven-day period.

The analysis included:

- Total electricity consumption
- Average daily consumption
- Deviation from the average
- Standard deviation
- Interpretation of daily energy consumption variation

## NumPy Concepts Used

Some of the NumPy concepts demonstrated in this project include:

- "np.array()"
- "np.sum()"
- "np.mean()"
- "np.arange()"
- "np.radians()"
- "np.sin()"
- "np.sqrt()"
- Element-wise array operations
- Mathematical sequences
